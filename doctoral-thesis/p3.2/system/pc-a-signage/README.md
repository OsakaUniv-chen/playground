# PC-A サイネージ端末

Linux 1 台の Chrome 全画面で、複数の Web ページを 10 秒ずつ巡回表示する。
**他の PC とは繋がらない**（設計 §1）ので、この系だけで完結している。

```bash
sudo apt install -y wmctrl xdotool     # X11 前提。Wayland では動かない

./signage.sh --check   # 依存・URL 疎通・設定の確認（GUI 不要）
./signage.sh           # 起動。Ctrl-C 一回で全ウィンドウごと終了
./signage.sh --stop    # 別ターミナルから止める場合
```

解像度は自動検出する。手元で現地を再現するときだけ `SIGNAGE_W=1920
SIGNAGE_H=1080 ./signage.sh`。表示秒数（`DWELL`）・拡大率（`ZOOM`）・通知の
抑止（`SUPPRESS_NOTIFICATIONS`）は `signage.sh` 冒頭の変数。

## 仕組み

URL ごとに Chrome ウィンドウを 1 つ全画面で**常駐**させ、`DWELL` 秒ごとに次を
最前面に出す。毎回起動し直さないのは、(1) 非力な端末ほど表示時間が起動と読み込みに
消える、(2) 常駐ならアニメーションが途切れない、(3) 現地でネットワークが切れても
最後の画面が残る、の 3 つのため。背面に回ったウィンドウの描画が止まらないよう
background throttling を切ってある。ウィンドウが落ちたら巡回時に検出して上げ直す。

X11 と Chrome まわりの実測知見（WM_CLASS の照合、`windowactivate` でないと
切り替わらない、Chrome の終了で孤児プロセスが残る、等）は `signage.sh` の
該当箇所にコメントで書いてある。

## コンテンツ

`urls.conf`（1 行 1 URL、行頭 `#` がコメント）。選定方針は 2 つ:

- **画面自体が動くもの**を優先する（変化が視線を引くため）
- **出典表記だけで自由利用できる公的データ源**を基本とする。気象庁ホームページは
  「公共データ利用規約（第 1.0 版）」に準拠し、出典を書けば自由に使える。
  論文や発表で画面を載せる場合もこの形にしておく

現在は気象庁の 3 ページ（天気予報／ひまわり衛星画像／地震情報）。交通は葛飾側で
対応するページが未確定のため保留。なお気象業務法第 23 条により気象庁以外は
警報を出せないので、気象アラートは自前で判定せず気象庁の発表をそのまま表示する。
